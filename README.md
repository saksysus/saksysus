### 🚀 About Me

Automation &amp; Robotics Engineering student passionate about embedded systems, robotics, IoT, and AI. I enjoy building intelligent hardware projects that solve real-world problems and documenting the journey from idea to prototype.

🔭 &nbsp;I'm currently working on **Embedded Systems, Robotics &amp; IoT projects**

👯 &nbsp;I'm looking to collaborate on **Open-source robotics, embedded systems &amp; IoT projects**
